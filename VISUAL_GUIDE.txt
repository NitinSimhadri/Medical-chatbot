## Theme Persistence

### How Theme System Works
```
1. User Clicks Moon/Sun Icon
   ↓
2. Theme Changes Immediately
   └─ Light → Dark
   └─ Dark → Light
   ↓
3. Saved to localStorage
   └─ Key: 'medibot-theme'
   └─ Value: 'light' or 'dark'
   ↓
4. Page Refresh
   └─ Theme Loaded from localStorage
   └─ User's preference persists
```

## API Integration Flow

### RAG Chain Process
```
User Message
    ↓
Service Keyword Check
    ├─ If medication related → Suggest medication service
    ├─ If symptom related → Suggest symptom checker
    ├─ If urgent → Emergency alert
    └─ Otherwise...
    ↓
RAG Chain
├─ Retrieve from Pinecone
├─ Use LangChain
├─ Groq LLM Generation
└─ Add Medical Disclaimer
    ↓
Bot Response
    ↓
Save to History
```

## Getting Started Summary

```
1. CREATE ENVIRONMENT
   conda create -n medibot python=3.11 -y
   conda activate medibot
           ↓
2. INSTALL DEPENDENCIES
   pip install -r requirements.txt
           ↓
3. CREATE .env FILE
   PINECONE_API_KEY=...
   GROQ_API_KEY=...
   SECRET_KEY=...
           ↓
4. RUN APPLICATION
   python app.py
           ↓
5. OPEN BROWSER
   http://localhost:8080
           ↓
6. TEST THEME
   Click moon/sun icon
           ↓
7. TEST CHAT
   Send a message
           ↓
8. EXPLORE SERVICES
   Click sidebar items
           ↓
✅ SUCCESS!
```
